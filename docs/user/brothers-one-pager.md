# AKPD Member Portal — Brothers Quick Reference

## Sign In
Go to [PORTAL_URL] → **Sign in with Google** → complete the one-time profile setup (name, city, interests).

---

## Update Your Profile
Avatar (top-right) → **Settings** → update name, location, LinkedIn, interests, photo → **Save Changes**.

---

## Post an Opportunity
**Opportunities** → **Post Opportunity** → fill in details → **Submit**.
Admin approves before it goes live — usually within 24 hours. Questions? [ADMIN_EMAIL]

---

## Write a Class Review
**Classes** → **Reviews** tab → **Write a Review** → enter course, ratings, focus areas, notes → **Submit**.

---

## Upload a Class Resource
**Classes** → **Resources** tab → **Add Resource** (or **"Add to [COURSE]"**) → upload file or paste URL → **Submit**.
Max file size: 50 MB.

---

## Download Recruitment Resources
**Recruitment** → click a career field → click a file to download or a link to open.
If a download doesn't start, click again (links are time-limited).
